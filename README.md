# Turn Lab — проект к Assignment 5

Небольшой адаптивный сайт о кубике Рубика. В нём реализованы все три части задания по основам JavaScript.

## Как открыть

Откройте `index.html` в браузере. Сервер и сторонние библиотеки не нужны. Шрифт загружается из Google Fonts, если интернет доступен; без него используются системные шрифты.

## Соответствие заданию

1. **Игра «Выше или ниже»** — вариант A. Случайное время сборки находится в диапазоне 5–35 секунд включительно. Есть три жизни, серия, лучший результат, проверка равенства и перезапуск без перезагрузки.
2. **Конфигуратор набора** — вариант B. Каталог из 12 объектов хранится в массиве, фильтруется поиском и категорией. Набор собирается по категориям; Bluetooth-таймер требует совместимый куб, а бюджет ограничивает выбор. До трёх сборок можно сохранить и сравнить.
3. **Создатель кубера** — вариант B. Предпросмотр меняется при вводе. Проверяются уникальность имени, ровно 20 очков, минимум навыка для класса и совместимость цвета с классом. Ошибки доступны с клавиатуры и связаны с полями формы.

## Файлы

- `index.html` — структура и пустые контейнеры каталога и результатов.
- `styles.css` — оформление и состояния элементов на узком и широком экране.
- `js/task1-game.js` — логика игры.
- `js/task2-configurator.js` — каталог и конструктор.
- `js/task3-character.js` — форма, проверка и карточка кубера.

Перед сдачей замените поля имени и группы в отчёте, добавьте ссылки на ваш GitHub-репозиторий и GitHub Pages после публикации. Проверьте, что можете объяснить правила игры, работу массива каталога и каждое правило формы.
